# vMix Ticker

브라우저에서 흐르는 자막(티커)을 띄우고, 그 화면을 **HDMI → 캡처보드 → vMix** 로 받아 송출하는 도구입니다.
문구는 조작 화면에서 실시간으로 쓰고, `반영`을 눌러야 송출됩니다.

```
[티커 PC]                                   [vMix PC]
  조작 화면 (index.html)  ──입력──┐
  송출 화면 (output.html) ──전체화면── HDMI ──▶ 캡처보드 ──▶ vMix 입력 ──▶ 크로마키 / 크롭 ──▶ Overlay
  (휴대폰·다른 노트북도 같은 Wi-Fi면 조작 가능 · 서버 모드)
```

## 실행 방법 (둘 중 하나)

| 방식 | 실행 | 조작 가능 기기 |
|---|---|---|
| **서버 모드 (권장)** | `run.bat` 더블클릭 (Node.js 필요) | 티커 PC + 같은 네트워크의 휴대폰·노트북 |
| 로컬 모드 | `public\index.html` 더블클릭 | 티커 PC의 브라우저 창끼리만 |

- 서버 모드는 실행 창에 `다른 기기 : http://192.168.x.x:8787/` 주소가 나옵니다. 휴대폰 브라우저로 그 주소를 열면 됩니다.
  첫 실행 때 Windows 방화벽 창이 뜨면 **개인 네트워크 허용**을 누르세요.
- 공용 Wi-Fi라면 PIN을 거세요: 명령 창에서 `set TICKER_PIN=1234` 후 `node server.js --open`.
- 문구·디자인은 `data\state.json`에 저장되어 서버를 다시 켜도 유지됩니다.

## 현장 세팅 순서

1. **티커 PC 디스플레이**: HDMI(캡처보드)를 *확장* 모드로 연결 → 해당 디스플레이 해상도 **1920×1080**, 배율 **100%** 권장.
2. 조작 화면에서 **송출 창 열기** → 뜬 창을 캡처보드 쪽 화면으로 드래그 → **더블클릭(또는 F11)** 으로 전체화면.
   왼쪽 위 안내 상자에 실제 출력 해상도가 표시됩니다 (`I` 키로 다시 보기). 6초 뒤 자동으로 사라집니다.
3. **vMix**: `Add Input → Capture` 로 캡처보드 추가 → 입력 설정에서
   - **Colour Key → Chroma Key** (배경색 #00FF00), 또는
   - 바 영역만 남도록 **Crop** (키잉이 필요 없어 가장 깔끔)
4. 해당 입력을 **Overlay** 로 올립니다.

### 화질 팁
- 문구는 불투명한 바 안에 있으므로 키잉은 바 테두리에서만 일어납니다. **모서리 둥글기 0** 이 키 경계가 가장 깨끗합니다.
- 바 배경을 초록 계열로 하면 키에 같이 빠집니다. 바 색이 초록이면 배경(키) 색을 블루/마젠타로 바꾸세요.
- 속도는 **60·120·180·240 px/초** 처럼 60의 배수가 60fps에서 프레임당 정수 픽셀로 움직여 가장 매끄럽습니다.
- Windows 알림·절전·화면 보호기를 끄고, 송출 창 위에 다른 창이 뜨지 않게 하세요.
- 글꼴(Pretendard)은 인터넷으로 받습니다. 오프라인이면 맑은 고딕으로 대체되며, 디자인 > 글자에서 PC 설치 글꼴을 직접 지정할 수 있습니다.

## 조작 화면 기능

- **공지 문구**: 여러 줄 관리, 체크로 송출 포함/제외, ↑↓ 순서 변경. `Enter` 다음 줄 추가.
  - **다음 바퀴부터 반영** (`Ctrl+Enter`): 흐름이 끊기지 않고, 지금 화면의 문구가 지나간 뒤 새 문구가 이어서 들어옵니다.
  - **즉시 교체** (`Ctrl+Shift+Enter`): 비우고 오른쪽 끝에서 다시 시작.
- **표시 중 / 숨김**: 바가 아래(위)로 미끄러져 들어가고 나옵니다.
- **긴급 공지**: 빨간 바로 즉시 교체, 해제하면 일반 공지로 복귀.
- **디자인**: 컬러 프리셋 6종, 위치(상/하단), 바 높이·여백·모서리, 표제(사선/사각/라운드)·로고, 글꼴·크기·굵기, 구분 기호·간격, 속도, 양끝 페이드, 긴급 공지 색.
  - **바 배경 이미지**: 피그마·포토샵으로 만든 바 그래픽(예: 1920×96 PNG)을 깔고 그 위로 문구만 흐르게. `바 높이를 이미지 비율에 맞추기`로 잘림 없이 맞춤. 그래픽에 표제 자리가 그려져 있으면 `표제 배경색 채우기`를 끄세요.
  - **고급: 사용자 CSS**: 패널에 없는 효과(그림자, 그라데이션 등)를 CSS로 덧씌움. `CSS 적용`을 눌러야 송출됩니다. 대상 클래스: `.bar` `.label` `.item` `.sep` `.logo`.
- **내 디자인**: 현재 디자인 전체를 이름 붙여 저장 → `적용` 한 번으로 전환. 서버 모드는 `data\designs.json`(모든 기기 공유), 로컬 모드는 그 브라우저에 저장.
- **설정 파일**: 행사별 문구+디자인(+내 디자인 목록)을 JSON으로 내보내고 현장에서 불러오기. 노트북 간 디자인 이전에도 사용.

## 파일 구조

```
run.bat            서버 실행 (Node.js 18+)
server.js          정적 파일 + 상태 저장 + SSE 실시간 전달 (외부 패키지 없음)
public/index.html  조작 화면      public/control.js, control.css
public/output.html 송출 화면 (1920×1080 기준, 창 크기에 맞춰 확대/축소)
public/ticker.js   공용: 기본값·프리셋, 동기화(서버/로컬), 티커 렌더러
```
